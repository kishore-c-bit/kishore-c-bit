### 🚀 Projects

#### 🛒 Farm Freshly - Full Stack eCommerce Website
`Python` `Django` `DRF` `React.js` `MySQL` `JWT`

- Online store with browsing, cart, wishlist, payments and order tracking, with a responsive React.js frontend
- 15+ REST APIs with DRF, JWT login/signup and separate customer and admin access levels
- Admin panel to manage products, orders and users
- MySQL query optimization with indexing for faster product pages under high traffic

#### 🐳 Full Stack E-Commerce Platform (Containerized)
`React.js` `Django` `DRF` `MySQL` `Docker` `Docker Compose` `JWT` `Email API`

- Frontend, backend and database run as separate containers with Docker Compose
- JWT authentication with token refresh, multi-criteria search and filters, product reviews and ratings
- Automatic order confirmation and shipping update emails through a third-party email API

#### 🛡️ Automated Web Application Security Testing Pipeline (OWASP ZAP)
`OWASP ZAP` `Docker` `GitHub Actions` `Python` `Juice Shop` `DVWA`

- Assessed deliberately vulnerable apps using spidering, passive and active scans, request interception and fuzzing, mapped to the OWASP Top 10
- ZAP baseline scans in a GitHub Actions pipeline that fails the build on high-risk alerts and publishes HTML reports
- Python scripts using the ZAP REST API to summarize alerts, plus a before and after rescan of a fixed sample app

#### 🔍 Mini SOC using Wazuh - Detection, Triage and Investigation
`Wazuh` `Linux` `Windows` `MITRE ATT&CK` `Active Response`

- Wazuh server with Windows and Linux agents in a virtual lab, with SOC dashboards
- Tested detections for brute-force logins, file integrity changes, vulnerabilities, CIS configuration checks, account activity and web server logs
- Triaged alerts, investigated incidents, wrote incident reports and used Active Response to block repeated failed logins

> 🔒 All security testing was done only on my own lab systems and deliberately vulnerable practice applications.
